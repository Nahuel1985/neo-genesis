# 🏥 Neo Genesis

> Innovando la medicina, humanizando la atención.

Neo Genesis es una plataforma médica moderna diseñada para ofrecer una experiencia simple, elegante y eficiente tanto para pacientes como para profesionales.

---

## 🚀 Objetivos

- Solicitud de turnos online.
- Chat inteligente para pacientes.
- Información médica organizada.
- Diseño centrado en la experiencia del usuario.
- Arquitectura escalable.
